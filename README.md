# AutoCare-Car-Maintenance-System
​نظام ويب متكامل لإدارة مراكز صيانة السيارات (AutoCare) مبني بلغة PHP 8 و MySQL، يدعم تعدد الصلاحيات (مدير، موظف، عميل)، إدارة أوامر الصيانة، الفواتير، المواعيد، المخزون، والتقارير المالية.   ​ AutoCare Car Maintenance Management System built with PHP 8, PDO, MySQL &amp; Vanilla JS (RBAC, Work Orders, Invoices, Appointments &amp; Inventory).
