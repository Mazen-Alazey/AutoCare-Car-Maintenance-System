# AutoCare-Car-Maintenance-System
​نظام ويب متكامل لإدارة مراكز صيانة السيارات (AutoCare) مبني بلغة PHP 8 و MySQL، يدعم تعدد الصلاحيات (مدير، موظف، عميل)، إدارة أوامر الصيانة، الفواتير، المواعيد، المخزون، والتقارير المالية.   ​ AutoCare Car Maintenance Management System built with PHP 8, PDO, MySQL &amp; Vanilla JS (RBAC, Work Orders, Invoices, Appointments &amp; Inventory).

ا
نظام AutoCare لإدارة مراكز صيانة السيارات
​عن المشروع (فكرة العمل):
مشروع AutoCare هو نظام ويب متكامل يهدف إلى تحويل العمل في مراكز وورش صيانة السيارات من النظام الورقي التقليدي إلى نظام رقمي منظم. يقوم النظام بربط إدارة المركز، الفنيين، والعملاء في منصة واحدة؛ لتسهيل متابعة السيارات منذ لحظة دخولها للفحص وتشخيص الأعطال، مروراً بعمليات الصيانة، وحتى إصدار الفاتورة النهائية وتسليم السيارة للعميل.  



​أبرز مميزات النظام:
​نظام صلاحيات متعدد (مدير، موظف، عميل): يوفر النظام لوحة تحكم خاصة لكل مستخدم حسب دوره، مع حماية خاصة لحساب "المدير الرئيسي" تتيح له إدارة حسابات المدراء الإضافيين وتخصيص الصلاحيات لكل موظف بدقة (مثل صلاحية منح الخصم، تعديل الأوامر، أو حذف السجلات).  


​إدارة أوامر الصيانة والسيارات: تسجيل بيانات المركبات، فتح كروت صيانة، تحديد الأعطال والتكلفة التقديرية والفعلية، وتوجيه الأمر للفني المختص مع تحديث حالة السيارة خطوة بخطوة (جديد، قيد الفحص، قيد الصيانة، مكتمل، تم التسليم).  


​الإدارة المالية وكشوفات الحساب: إصدار الفواتير، متابعة المبالغ المحصلة والمتبقية، دعم طرق دفع متعددة (نقداً، بطاقة، تحويل بنكي)، وإمكانية طباعة كشف حساب مالي شامل لكل عميل مع إشعارات فورية للإدارة عند الدفع.  
​حجز المواعيد وإدارة قطع الغيار: إمكانية حجز مواعيد الصيانة مسبقاً وربطها بالخدمة المطلوبة، بالإضافة إلى قسم لإدارة مخزون قطع الغيار ومتابعة الكميات والأسعار.  


​الأمان والرقابة وحفظ البيانات: يتضمن النظام سجل تدقيق (Audit Log) يوثق كافة العمليات التي تتم داخل الموقع، وسلة محذوفات لاستعادة الحسابات المحذوفة، وميزة أخذ نسخة احتياطية كاملة لقاعدة البيانات بصيغة SQL بضغطة زر.  
​واجهة عربية متجاوبة: تصميم يدعم اللغة العربية بالكامل ويتوافق مع شاشات الجوال والكمبيوتر، مع ميزة التبديل السريع بين المظهر الليلي والنهاري (Dark / Light Mode).  


​اللغات والتقنيات المستخدمة في بناء المشروع:
​PHP 8 (PDO): لبناء الواجهة الخلفية (Backend)، إدارة الجلسات والصلاحيات، وتأمين النظام ضد ثغرات حقن قواعد البيانات (SQL Injection) وهجمات (CSRF).  

​MySQL: لتصميم قاعدة البيانات العلائقية وحفظ سجلات المستخدمين، العملاء، السيارات، الفواتير، وأوامر الصيانة.  

​HTML5 & CSS3: لبناء هيكل الصفحات وتنسيق الجداول والبطاقات الإحصائية بالاتجاه العربي (RTL).  

​JavaScript (Vanilla JS): للتحكم في النوافذ المنبثقة (Modals)، القائمة الجانبية في الجوال، وحفظ إعدادات المظهر الليلي والنهاري بدون الاعتماد على مكتبات خارجية ثقيلة
